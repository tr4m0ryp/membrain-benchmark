Reading the two error floors: `Bayes err any f(s)` is a KDE estimate and is biased UP by smoothing, while the oracle `threshold Bayes err` is biased DOWN because tau is fitted on the same pairs. At the class sizes here the first can exceed the second; the theoretical ordering (any `f` beats any threshold) only becomes recoverable at large n, so neither is quoted as bounding the other.

`pooled` is deliberately reported and deliberately not the headline. It is BELOW both regimes because the optimum lives at a different place in each, so a single tau cannot serve them at once. That is Theorem 1's non-functionality claim showing up directly in the measurement rather than in the argument.

Sensitivity, the literal action map with cross-workstream pairs counted as interference (the population `manifest.conventions` excludes):

That sensitivity is why the population matters: read literally, the action map fires K1 in BOTH regimes. It gets there by counting 10039 cross-workstream pairs per regime as interference, which no collision probe would ever surface, so it answers a different question than the one K1 asks.
